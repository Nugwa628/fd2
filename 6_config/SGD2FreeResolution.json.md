## Findings

* **The shipped SGD2FreeRes.dll is not a plain build of the 3.0.3.1 tag.** Its link timestamp is 2023-05-02 20:31:58
  UTC while its version resource says Build 2022-10-27; none of the 17 gateway SHA-1 strings of the tag's online
  resolution table ([helper/game_resolution.cc:96-285](https://github.com/mir-diablo-ii-tools/SlashGaming-Diablo-II-Free-Resolution/blob/14ffbcfd8924a45d97e06acd80607ee7f87ecdc5/SlashGaming-Diablo-II-Free-Resolution/src/helper/game_resolution.cc#L96)) are in the binary, the
  default literal `"640x480"` is absent and `"1068x600"` is present. The SHA-1 of PD2's realm gateway (the
  `aux_battle_net` default of ProjectDiablo.json) is not in the tag's table either, so stock 3.0.3.1 would offer only
  640x480/800x600 on PD2's realm. The rebuild most likely hard-wires PD2's resolution; confirming it would need the DLL
  to be decompiled, which is out of scope here. The key schema above is the same in the binary (all key strings
  present).
* `Ingame Resolution Mode` is the only key the DLL writes during play (resolution changes in the options menu).
