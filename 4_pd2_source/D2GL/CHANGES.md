# PD2 D2GL fork: changes vs upstream v1.3.3

- Fork: https://github.com/Project-Diablo-2/d2gl
- Upstream: https://github.com/bayaraa/d2gl, tag `v1.3.3` (`2bbec75`)
- Shipped build: fork commit `9443840` (see [README.md](README.md))

The tables below are generated by `tools/launcher/d2gl_changes_md.py <clone> v1.3.3 9443840`. In the file table, `option/ini.*` were deleted, so their links point at nothing.

Note on history: the fork's own commits start in March 2023 on top of upstream `v1.0.4-6-g2b3cf17`. The fork merged upstream v1.3.1 on 2023-08-11 (`0600eb9`) and upstream `master` (= v1.3.3 + `919df35`) on 2024-03-20 (`ba85cd2`). `v1.3.3..HEAD` therefore lists 30 PD2 commits from 2023 together with the post-merge work.
